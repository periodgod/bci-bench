## Platform

web

（实际以 pywebview + WebView2 原生窗口运行在 Windows 上，打包为单文件 exe；界面是本地 HTML/CSS/JS，另有仅本机回环的浏览器模式。）

## Users

- 主要用户（推断）：实验室里使用 `wyu_bci_bench` 做脑电（EEG）解码实验的研究生和本科生，包括刚入组的新生。他们需要知道 bench 里有什么、某个函数在哪、怎么用、可不可信。
- 次要用户（推断）：熟悉代码的维护者，用它快速跳到模块源码、查看引用关系和改动影响面；导师或审稿人，用来核对“这个接口声称解决了什么”和核验记录。

## Product Purpose

把 bench 源码实时扫描成可浏览的目录：十个功能分层、模块、公开函数和类（签名、中英文说明、带行号源码）、能力标签（流程阶段 / 方法机制 / 处理目标 + 声明等级）、模块依赖图、旧脚本到 bench 的对照、测试与等价核验结果。成功的标志：新生不读源码也能找到该用的接口，并分清它“声称做什么”和“被验证过什么”。

## Positioning

不是通用 API 文档站。它把每个接口的**声明等级**（机制 / 设计意图 / 评估用途 / 度量 / 产物管理）和**核验结果**（与历史实现逐项等价核验，29/29）放在接口旁边。这是本项目证据纪律的界面化：区分“希望缓解域偏移”和“只用于评估域偏移”。

## Operating Context

- 在实验室 Windows 工作站上，与代码编辑器、终端、实验结果文件并排使用；窗口常最大化，也会缩到半屏。
- 启动时实时扫描 `D:\脑电大模型\wyu-bci-bench` 源码；找不到源码时退回内置快照。
- “重新扫描源码”在跑完 `verify_proteus_port.py` 或改代码后使用。
- 相邻工件：交接文档、结果展示页 `实验结果汇总/index.html`、论文阶段稿。

## Capabilities and Constraints

- 界面语言中文；标识符、签名、源码保持英文原样。类说明有中文摘要字段 `summary_zh` 和英文 docstring 两层。
- 离线运行：不得依赖外部字体、CDN 或网络请求。
- `app.js` 由数据驱动渲染，数据结构见 `build_catalog.py`；视图路由用 URL hash（含能力筛选状态）。
- `open_file` 只允许打开 bench 目录内的文件。
- 交互测试曾覆盖筛选计数、行内 OR / 跨行 AND、hash、标签跳转（H-20261021-06），重设计不得破坏这些行为。

- 名称 “WYU-BCI Bench Explorer”。无既定 logo 或品牌色（推断）。
- 2026-10-21 10:54–11:02 有一版未记录日志的暗色改版，CSS 注释称参考 Dribbble 上 “SpendIQ” SaaS 作品；是否为用户指定的方向未确认（推断：用户偏好暗色界面）。

## Evidence on Hand

- 真实数据全部来自实时扫描：27 个模块、6,339 行、126 个公开函数、30 个公开类、36 个测试、21 条能力标签、20 条迁移对照、核验 29/29（2026-10-21 扫描值，会变）。
- 不得编造性能数字或“效果提升”类声明；PROTEUS 十名公开参与者的数字只算开发证据。

## Product Principles

1. 证据等级永远可见：声明等级与核验结果不被装饰淹没。
2. 找得到优先于好看：模块、函数、源码三步内可达，搜索随时可用（`/` 快捷键）。
3. 代码原样呈现：标识符、签名、行号与文件一致。
4. 对新生友好，对熟手不拖沓：中文解释在前，英文原文与源码一步可得。

## Accessibility & Inclusion

正文对比度至少 4.5:1；全部功能可键盘操作（依赖图节点可 Tab/Enter）；窄窗口下侧栏可折叠。
